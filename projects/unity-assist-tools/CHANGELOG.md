# Unity Assist Texture Color Engine 更新履歴

## 0.1.0-preview.6（現時点の最終版）

### 変更内容

preview.6では、利用者が操作する際に必要のない開発時向けの説明をエディター画面から取り除き、画面上の表記を整理しました。Unityメニュー名とウィンドウ名を「Texture Color Replacer」に統一し、内部の読み込み方式や実装構造を説明する表示も削除しています。

変換先の色指定は、従来のHEXコード入力からUnity標準のカラーピッカーに変更しました。色相リングと色選択フィールドを使って、色を視覚的に選択できます。単色変換では変換先を1色、2点方式では変換先を2色指定します。

このバージョンでは、色変換エンジン、画像読み込み、色判定、変換、PNG出力の内部処理には変更を加えていません。

### 動作確認

利用者によるVRChatアバター2体の衣装テクスチャを使った動作確認が行われ、衣装の色変換では異常がなかったとの報告を受けています。一方、アバターの身体・肌色の変換は衣装テクスチャと比べて苦手であることが確認されました。この点は現時点での既知の制限として扱います。

Unity Test Runner向けのNUnitテスト8件は作成済みですが、Unity Test Runnerでの実行結果は未確認です。

### 参考にした既存ツール・技術

既存製品の公開仕様、マニュアル、変更履歴、公開ソースのライセンスを調査し、以下の考え方を設計上の参考にしました。ここに記載する内容は公開情報に基づく技術調査であり、各製品の品質や精度を同一条件で比較したベンチマークではありません。

- **Iroca：** 素材の明暗に応じた色域推定、影・ハイライトの扱い、境界の色残りを抑える考え方を調査しました。
- **Color-Changer / Color-Changer for Unity：** 変更前後の色の差分を利用する変換、RuntimeとEditorの分離、プレビューと出力の考え方を調査しました。
- **Texture Color Adjuster / TexColorAdjuster：** 色分布の比較、明度に応じた色合わせ、プレビューと保存結果を一致させる考え方を調査しました。
- **Color Matcher / Miyabix Tool：** Unityのインポート後の画像だけに依存せず、元画像を読み込む考え方を調査しました。
- **Click Recolor / TexStack / Avenix Studio：** 色だけでは区別が難しい領域に対して、UV・メッシュ情報を活用する考え方を調査しました。
- **Photoshop / Krita / F Texture Tools / Color Studio 10 / ReColor Pro：** 色域選択、類似色選択、選択処理と色変換処理を分ける設計を調査しました。

### ライセンス・第三者コンテンツの確認

preview.6の配布物を確認した範囲では、調査対象製品のソースコード、DLL、シェーダー、画像、モデル等は同梱していません。

IrocaはPolyForm Shield License 1.0.0で提供され、競合利用に関する制限があるため、ソースコード・実装コード・アセット・派生コードをコピーまたは移植していません。公開されている製品説明や機能の概要を、独立実装のための高レベルな設計参考として調査しました。

Color-Changer、Color-Changer for Unity、Texture Color Adjuster等のMITライセンスのプロジェクトも参考対象として調査しましたが、preview.6にはそれらのソースコードを取り込んでいません。BOOTHおよびUnity Asset Storeの製品については、コード再利用の許可が明確でないものや再配布制限があるものを、公開仕様のみの参考とし、ソースコード、アセット、シェーダー、説明書等を抽出・再配布していません。

将来、第三者コードを採用する場合は、対象バージョンのLICENSE・NOTICE・依存ライブラリ・配布条件を事前に確認します。必要な著作権表示とライセンス全文を同梱し、出典と採用箇所を記録します。本記録は確認時点の配布物と公開ライセンス情報に基づくものであり、第三者権利者による法的な保証を意味しません。

### 既知の制限

- 同じ色・同じ色分布を持つ別パーツが同一画像内にある場合、色情報だけでは完全に区別できません。
- 非常に暗く彩度の低い有彩色と黒色の境界は、元画像だけでは曖昧になる場合があります。
- 身体・肌色テクスチャの変換は、衣装テクスチャほど安定していません。
- 主にsRGBのBaseColorテクスチャを対象とします。Normal、Mask、MetallicなどのLinearデータには使用しないでください。
- PNG/JPG/JPEGは元ファイルから直接読み込みます。TGAは対応する非圧縮/RLE形式を読み込みます。非対応形式はUnityのインポート済みテクスチャを使う場合があります。

### 現在の位置づけ

v0.1.0-preview.6を現時点での最終版とします。現時点では追加の機能変更、UI変更、内部エンジン変更を行わず、衣装テクスチャ向けの操作性と変換結果を維持します。

# Unity Project File Colorizer 更新履歴

## Release 1.4.2 Preview

### 概要

今回のアップデートでは、Project File Colorizerを中心に機能を拡張しました。従来の拡張子による自動色分け機能を維持しながら、ユーザーが任意のアセットにカラータグを設定し、色別に分類・管理できる機能を追加しました。実際のファイルやフォルダ構成を変更せず、異なる場所に存在するアセットを疑似的なグループとして整理できるようにしています。

### 1. 手動カラータグ機能の追加

Projectウィンドウから、ユーザーが任意のアセットにカラータグを設定できる機能を追加しました。右クリックメニューから8色のプリセットカラーを選択できるほか、カスタムカラーの設定、複数アセットへの一括カラー設定、設定したカラータグの解除にも対応しました。従来の拡張子による自動分類だけでなく、ユーザー自身の目的や用途に応じてアセットを整理できます。

### 2. カラーグループ機能の追加

設定したカラータグを利用して、アセットを色別に一覧管理できる機能を追加しました。カラーごとのアセット一覧表示、アセット名・ファイルパスによる検索、一覧から対象アセットを選択・強調表示する機能を備えています。一覧から対象アセットの場所へ移動・表示でき、実際の保存場所やフォルダ構成に依存せず、同じカラーが設定されたアセットをまとめて管理できます。

### 3. 既存の自動色分け機能との統合

従来の拡張子別自動色分け機能を維持し、手動カラータグと共存できるようにしました。既存の9種類の拡張子別自動分類を維持し、手動カラータグがある場合は手動カラーを優先します。手動カラータグの解除後は従来の自動色分けに復帰し、既存のカラー設定も維持します。また、色分け機能のON/OFFに対応しました。

### 4. 設定保存・データ管理の改善

手動カラータグを継続して利用できるよう、アセットGUIDを利用した管理方式を採用しました。GUIDを基準としてアセットとカラーを対応付け、ProjectSettingsへの手動カラー設定の保存、アセットの移動・改名を考慮した管理処理、設定保存時のバックアップ、保存後のデータ検証、保存に失敗した場合の復旧処理を追加しました。

カラータグの設定によってアセット本体、ファイル名、`.meta` ファイル、実際のフォルダ構成は変更しません。Projectウィンドウの描画中はメモリ上のGUID辞書だけを参照し、設定ファイルI/Oや全アセット検索を行わない設計としています。

### 5. 不具合修正

Release 1.4.1で発生したコンパイルエラーを修正しました。`EditorGUILayout.ColorField` の引数指定を修正し、`GUIContent` を使用する呼び出し形式に変更することで、カスタムカラー設定画面のコンパイルエラーに対応しました。

### 6. 動作確認結果

Unity Editor上で、拡張子による自動色分け、色分け機能のON/OFF、任意の色を指定したカラータグ設定、指定タグによるアセットの分類・一覧管理、一覧から対象アセットの場所へ移動・表示する操作を確認しました。確認した範囲では、上記の操作に問題はありませんでした。

### 7. 静的検査・品質管理

ソースコードおよびパッケージ構成について、`package.json` のJSON構文、Assembly DefinitionのJSON構文、同梱 `.meta` ファイルのGUID重複、ZIPファイルの整合性を確認しました。また、旧Release 1.3.0のバックアップが元ファイルと一致することを確認しました。

今回の開発では、過去の正常動作版を基準とし、変更範囲をProject File Colorizerに限定しました。Transform HelperおよびTexture Color Replacerのソースコードは変更せず、既存機能への影響を抑える方針を採用しています。

### 8. 今後の改善予定

- 大規模プロジェクトでの処理速度・安定性の検証
- 複数アセット操作時の安定性確認
- アセット移動・改名・削除後の設定維持に関する追加検証
- カラーグループの操作性改善
- 設定管理機能の拡張
