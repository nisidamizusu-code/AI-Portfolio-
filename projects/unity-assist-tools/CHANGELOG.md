# Unity Assist Tools 更新履歴

## Release 1.4.2 Preview

### 主な更新内容

Project File Colorizerに、ユーザーが任意のアセットへ手動でカラータグを設定できる機能を追加。

従来の拡張子による自動色分けに加えて、ユーザー自身がアセットを分類・整理できるように機能を拡張しました。

### 1. 手動カラータグ機能の追加

- Projectウィンドウの右クリックメニューからカラーを設定可能に変更
- 8色のプリセットカラーを追加
- カスタムカラーの設定に対応
- 複数アセットへの一括カラー設定に対応
- 設定したカラータグの解除に対応

### 2. カラーグループ機能の追加

- カラーごとにアセットを一覧表示する機能を追加
- アセット名・パスによる検索に対応
- 一覧から対象アセットを選択・強調表示する機能を追加
- カラータグを利用した疑似的なファイル分類を実現

実際のファイルやフォルダを移動せず、異なる場所にあるアセットを同じカラーグループとして管理できるようにしました。

### 3. 既存機能との互換性

- 従来の9種類の拡張子別自動色分けを維持
- 手動カラー設定がある場合は手動カラーを優先
- 手動カラー解除時は従来の自動色分けに復帰
- 既存の色設定およびON/OFF機能を維持
- アセット本体や`.meta`ファイルを変更しない設計

### 4. 設定保存・安定性の改善

- アセットGUIDを利用したカラータグ管理
- ProjectSettingsへの設定保存
- アセットの移動・改名後もカラー設定を維持する構成
- 設定保存時のバックアップと復旧処理を追加
- Projectウィンドウの描画処理で不要な全件検索を行わない構成に変更

### 5. 不具合修正

Release 1.4.1で発生したコンパイルエラーを修正。

- `EditorGUILayout.ColorField`の引数指定を修正
- Unity 2021.3とのAPI互換性を考慮した呼び出しに変更
- カスタムカラー設定画面のコンパイルエラーに対応

### 6. 開発・品質管理について

今回の更新では、既存機能を維持したまま新機能を追加することを重視しました。

また、過去の正常動作版を基準として、変更範囲をProject File Colorizerに限定し、ほかのツールへの影響を抑える方針を採用しています。

静的検査、パッケージ構成、ZIP整合性などを確認しています。

※Unity Editor上でのコンパイルおよび実操作については、利用環境での最終確認が必要です。
