# Unity Assist Tools

## 1. 概要

Unity Assist Toolsは、Unityでの開発作業を支援するために制作したツール群です。

Unity Editor上で利用できる機能を開発し、作業効率や操作性の向上を目指しています。

アセットの種類別色分け、オブジェクトの位置・回転・サイズの一括調整、テクスチャの色変更など、Unity 

Editor上でのさまざまな作業を補助する機能を備えています。

## 2. 開発目的

Unityでの開発作業をより簡単かつ効率的に進められるようにすることを目的としています。

特に、機能の使いやすさや操作画面の分かりやすさを重視しています。

## 3. 使用技術

- C#
- Unity
- Unity Editor

## 4. AIの活用

本プロジェクトでは、ChatGPTとGitHub Copilotを活用しています。

- ChatGPT：設計相談、コード生成、既存コードの解析支援、改善案の検討
- GitHub Copilot：コード生成、コード補完、実装支援

AIを活用しながら開発を進め、提案された内容を確認して改善方針を決定しています。

## 9. 導入方法 

本ツール群は、Unity Package Managerから導入できます。

### 必要環境
- Unity 2021.3以上

### インストール手順

1. ダウンロードしたZIPファイルを解凍します。
2. Unityで導入先のプロジェクトを開きます。
3. メニューから `Window > Package Manager` を開きます。
4. Package Managerの「＋」ボタンを押します。
5. `Add package from disk...` を選択します。
6. 解凍したフォルダ内にある各ツールの `package.json` を選択します。
7. 残りのツールについても同じ操作を繰り返します。

### 導入するパッケージ

- `unityアシストツール/package.json`
- `unityアシストトランスフォームツール/package.json`
- `unityテクスチャ色置換ツール/package.json`

### 注意事項
- 3つのパッケージは個別に導入してください。
- 導入前にUnityプロジェクトのバックアップを推奨します。
- 導入後、Unityのコンパイルが完了するまで待ってください。
