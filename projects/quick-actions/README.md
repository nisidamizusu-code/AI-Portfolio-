# Quick Actions

## 1. 概要

Quick Actionsは、Visual Studio Code（VS Code）の初心者向け開発支援拡張機能です。

ボタン操作によって開発作業を簡単に行えるようにし、初心者でも扱いやすい環境を目指して開発しています。

## 2. 開発目的

VS Codeには多くの機能がありますが、初心者には操作方法が分かりにくいことがあります。

そこで、よく使う操作をGUI上のボタンにまとめ、簡単に利用できる拡張機能を作成しました。

## 3. 使用技術

- JavaScript
- HTML
- CSS
- Visual Studio Code Extension API

## 4. 主な機能

- ボタンによる開発操作の補助
- コードテンプレートの挿入
- コードの文字変換
- 余分な空白の削除

## 5. AIの活用

本プロジェクトでは、ChatGPTとGitHub Copilotを活用しています。

AIを利用してコードの生成・修正や仕様の検討を行い、開発を進めています。

AIの提案をそのまま採用するのではなく、開発目的や操作性を考慮して改善内容を判断しています。

## 6. 自分が取り組んだこと

- 初心者向けという開発コンセプトの決定
- 必要な機能の検討
- UIやボタン配置の改善方針の決定
- AIへの指示内容の検討
- 生成されたコードや提案内容の確認
- バージョンごとの操作性や機能の比較

## 7. 開発で重視していること

- 初心者でも分かりやすい操作性
- 既存機能の使いやすさ
- 動作の安定性
- 必要な機能を分かりやすく提供すること
