# Quick Actions

## 1. 概要

Quick Actionsは、Visual Studio Code（VS Code）の初心者向け開発支援拡張機能です。

ボタン操作によって開発作業を簡単に行えるようにし、初心者でも扱いやすい環境を目指して開発しています。

## 2. 開発目的

VS Codeには多くの機能がありますが、初心者には操作方法が分かりにくいことがあります。

そこで、よく使う操作をGUI上のボタンにまとめ、簡単に利用できる拡張機能を作成しました。

## 3. 使用技術

- JavaScript
- HTML
- CSS
- Visual Studio Code Extension API

## 4. 主な機能

- ボタンによる開発操作の補助
- コードテンプレートの挿入
- コードの文字変換
- 余分な空白の削除

## 5. AIの活用

本プロジェクトでは、ChatGPTとGitHub Copilotを活用しています。

AIを利用してコードの生成・修正や仕様の検討を行い、開発を進めています。

AIの提案をそのまま採用するのではなく、開発目的や操作性を考慮して改善内容を判断しています。

## 10. 導入方法

本拡張機能は、VS CodeのVSIX形式でインストールできます。

### 必要環境
- Visual Studio Code 1.106.0以上

### インストール手順

1. GitHubからZIPファイルをダウンロードします。
2. ダウンロードしたZIPファイルを解凍します。
3. 解凍したフォルダ内にある `unityassist-undo-redo-panel-1.7.0.vsix` を確認します。
4. VS Codeを起動します。
5. 左側の拡張機能アイコンを開きます。
6. 拡張機能ビュー右上の「…」をクリックします。
7. `Install from VSIX...` を選択します。
8. `unityassist-undo-redo-panel-1.7.0.vsix` を選択します。
9. インストール後、VS Codeを再読み込みします。

### 使用方法

インストール後、VS Codeの右側にあるSecondary Side BarからQuick Actionsを開きます。

右側のサイドバーが表示されていない場合は、メニューの「表示」から「外観」→「セカンダリ サイドバー」を選択してください。

## 注意事項
