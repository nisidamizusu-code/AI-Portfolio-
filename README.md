# AI Development Portfolio

## 概要

生成AIを活用したソフトウェア開発の経験をまとめたポートフォリオです。

ChatGPTとGitHub Copilotを活用しながら、ツールやアプリケーションの開発に取り組んでいます。

AIによるコード生成だけでなく、仕様の検討、機能の改善、生成されたコードの確認なども行っています。

## 使用AI

- ChatGPT
- GitHub Copilot

## 開発実績

### 1. Quick Actions
VS Code初心者向けの開発支援拡張機能。

### 2. Unity Assist Tools
Unityでの開発作業を支援するツール群。

## 開発方針

- AIを活用した効率的な開発
- 開発目的や仕様を自分で考える
- AIが生成したコードや提案を確認する
- 問題点を発見し、改善を繰り返す
  
## 動作確認・評価

### 動作確認結果
- 通常の使用において、各機能が想定した目的に沿って動作することを確認。
- 基本的な操作や機能の実行については、現時点で大きな問題なし。
- UIの視認性や操作性についても、問題なく利用できることを確認。

### 確認された課題
- 想定外の操作や入力など、通常とは異なる状況ではエラーや予期しない動作が発生する可能性がある。
- すべての例外的な状況に対する動作検証は今後の課題。

### 今後の改善方針
- 想定外の操作に対するエラー対策
- 例外的な状況での動作確認
- 安定性と安全性の向上
